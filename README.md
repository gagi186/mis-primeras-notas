# Mis primeras notas

App web para tablets que enseña a leer y escribir música tocando el pentagrama.
Cada nota tiene su color (Do rojo, Re verde, Mi azul, Fa café, Sol amarillo, La rosa, Si morado)
y se avanza por niveles: notas, ritmo, compás, silencios, puntillo, alteraciones, armaduras y semicorcheas.

**Abrir la app:** https://gagi186.github.io/mis-primeras-notas/

En el iPad: ábrela en Safari → Compartir → *Agregar a pantalla de inicio*.
Funciona sin conexión después de abrirla una vez. Las canciones se guardan en cada dispositivo.

Es un solo archivo (`index.html`), sin dependencias ni compilación.
La clave de sol es un trazado de dominio público de Wikimedia Commons (File:GClef.svg).
